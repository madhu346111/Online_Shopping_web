# Online_Shopping_web
🛍️ SmartCart - Online Shopping Website
📌 Project Overview

SmartCart is a simple and interactive online shopping website built using HTML, CSS, and JavaScript.
It includes features like login system, product listing, cart, wishlist, filters, and product details modal.

🚀 Features
🔐 Login System
User authentication using LocalStorage
Auto login support
🛒 Shopping Cart
Add/remove items
Dynamic cart count
❤️ Wishlist
Save favorite products
Remove items easily
🔍 Search & Filters
Search products by name
Filter by:
Category
Price
Rating
🖼️ Product Display
Grid layout with images
Product details popup
🎞️ Banner Slider
Auto sliding images
Manual navigation (prev/next)
📷 Image Search (Basic)
Upload image to find matching products (filename-based)
🎨 Modern UI
Animated gradient background
Hover effects & transitions
Glassmorphism login box
🛠️ Technologies Used
HTML5
CSS3 (Animations, Flexbox, Grid)
JavaScript (DOM Manipulation, LocalStorage)
